Supaya foto langsung masuk ke akun Google Drive pribadi kamu (bebas error kuota Service Account):

  1. Buka Google Cloud Console ➔ APIs & Services ➔ Credentials.
  2. Klik + Create Credentials ➔ OAuth client ID (Tipe: Web application).
  3. Pada Authorized redirect URIs masukkan: http://localhost:3000/api/auth/google/callback
  4. Salin Client ID & Client Secret ke form di bawah:
